### 语音识别（给流水号文件命名）
- faster-whisper small + CTranslate2 int8，venv `~/.workbuddy/binaries/python/envs/asr`。
- **坑1**：PyAV 19 与 faster-whisper 1.2.1 不兼容（`metadata_errors` 参数），PyAV 14 在 Python 3.13 无 wheel。
  → 改用 `soundfile` 自行解码 + 线性插值重采样到 16k，喂 numpy 数组给 `transcribe()`。
- **坑2**：hf-mirror 只有 28KB/s，xet 通道 401。→ **ModelScope `pengzhendong/faster-whisper-small` 有 3.9MB/s**，`model.bin` 462MB 一分钟下完。
- **坑3**：本机 CPU 极慢，每条音频固定 **~13 秒**（与时长无关，疑为补零到 30s）。645 条串行要 2.3 小时。
  → 改 4 进程并行（`tools/asr_parallel.py`），约 1.5 小时。
- whisper 常输出繁体 → `opencc-python-reimplemented` 的 `t2v` t2s 转换。

## 滑雪大冒险 - USB 传输问题与无线调试尝试（19:00-19:35）
- **USB 大文件传输彻底不可用**：pull / exec-out / cat 只要传超过约 1MB 就断线，设备随后从 adb devices 消失；小指令（getprop/ls/dumpsys）尚可。
- 手表系统信息：`ro.adb.secure=1`、`ro.debuggable=0`、SDK 30、`user` 版 → **无 root，必须密钥/TLS 认证，不能绕过无线配对**。
- 无线调试尝试结果：
  - 手表 WiFi IP `172.29.169.177`，`adb tcpip 5555` 执行成功，`netstat` 确认 5555 在 LISTEN 且曾出现 ESTABLISHED；
  - 但 `adb connect` 状态 `offline` → Android 11 的 adbd TLS 配对未完成，`settings get global adb_wifi_enabled` = 0（无线调试开关确实没打开）；
  - `stop adbd / start adbd` 需 root，不可用；mDNS 无服务发现。
- **结论**：无线调试必须走系统设置里的「无线调试」配对（一加手表二 UI 缺失/不可用），adb 无法强制打开。
- 备选：手机中转（OTG 读手表 / 手表传网盘 / 手机 WiFi 推送）；或手表本地操作。
